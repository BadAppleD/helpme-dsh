# HelpMe DSH plugin

This plugin bundles a concise `SessionStart` routing hint and one self-describing local DSH MCP bridge with named persistent-session management. The plugin manages a singleton DSH Host at `127.0.0.1:3080`, so Codex and the browser UI share all subagent Sessions. The bridge subscribes to each Session's persisted events for event-driven final completion; it does not forward token streams. It does not install a Skill or Codex custom subagent. The repository also provides `scripts/update.sh` for non-destructive in-place updates. See the repository [README](../../README.md) for installation, update, configuration, and security guidance.
